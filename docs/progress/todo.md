# 프로젝트 요약
주문 플랫폼의 분산 환경 시스템을 구현

## 프로젝트 내 기능
- POST /orders 
- GET /orders/{orderNumber} 
- POST /orders/{id}/cancel

## 목적
- 도메인 유즈케이스는 단순화 하되, 분산환경에서 사용하는 다양한 기법 (예. SAGA 패턴, 동시성) 을 익힌다
- 부하테스트에서 트래픽을 충분히 견디도록 설계한다.
