# ADR-0005: 프로젝트 구조 — 별도 모듈 vs 패키지

- **상태**: Accepted (2026-06-27)
---

## 1. 맥락 (Context)

- 바운디드 컨텍스트(order·payment·inventory)를 어떻게 구별할것인지 확정 필요

---

## 2. 결정 기준
- 1순위: **마이크로서비스 전환 적합성**
  - 나중에 컨텍스트를 독립 배포로 쪼개기 쉬운가
- 2순위: 레이어 규칙·컨텍스트 격리가 자동으로 강제되는가

---
## 3. 결정 : 컨텍스트당 단일 모듈 채택
- 컨텍스트별로 모듈을 나눈다.
    - 총 5모듈(shared·order·payment·inventory·bootstrap)
- 그 안에서 domain·application·infrastructure를 **패키지**로 나눈다


결정 근거:
- **MSA 전환 난이도**: 나중에 컨텍스트를 독립 마이크로서비스로 쪼갤 때, 분리 단위는 모듈(=컨텍스트)이므로 쉽게 분리 가능하다.
